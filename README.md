# 🐾 PawRescue – Animal Rescue and Adoption Management System

## 📌 About the Project

PawRescue is a Java Full Stack web application designed to help people report stray or injured animals, register as volunteers, and submit adoption requests.

The system provides an admin dashboard to manage animal reports, volunteer registrations, and adoption requests.

## ✨ Features

- 🐶 **Report an Animal:** Report stray, injured, or animals needing help.
- ❤️ **Volunteer Registration:** Register as a volunteer to support animal rescue activities.
- 🏡 **Animal Adoption:** Submit adoption requests to give animals a loving home.
- 🔍 **Track Adoption:** Check adoption request status using an email address.
- 👨‍💼 **Admin Dashboard:** View and manage animal reports, volunteers, and adoption requests.
- 📊 **Database Integration:** Store and manage information using an H2 database.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/vinuthavbasavanapade-sketch/PawRescue.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open the terminal in the project directory.

4. Run the application:

   ```powershell
   .\mvnw.cmd spring-boot:run
   ```

5. Open your browser and visit:

   http://localhost:8080
